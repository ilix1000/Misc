# Files to copy to the SD card

Copy the contents of this folder to the root of the SD card (so you get
`/roms/doom/DOOM1.WAD` on the card).

- `roms/doom/DOOM1.WAD`: the shareware version of Doom (Episode 1, "Knee-Deep
  in the Dead"), by id Software. The shareware episode may be shared freely as
  long as it is unmodified and not sold. Bought the full game? Put your
  `DOOM.WAD` / `DOOM2.WAD` next to it. Free alternative: Freedoom
  (https://freedoom.github.io), `freedoom1.wad` / `freedoom2.wad`.
